# VIKZ-Gemeinden – Gemeindesuche nach Entfernung

Statische Seite: zeigt alle 291 Standorte aus den Gemeindelisten der VIKZ-Landesverbände,
sortiert nach Entfernung zum eigenen Standort (oder zu einer eingegebenen Adresse).

- Standort: Browser-Geolocation, Berechnung ausschließlich lokal (Haversine).
- Fallback: Adresse mit Straße und Hausnummer (Photon, Reserve: Nominatim).
- Direktlinks je Eintrag: Route (Google Maps), OpenStreetMap, Telefon, E-Mail, Website.
- Datengrundlage: Stand 24.10.2026. Karten: © OpenStreetMap-Mitwirkende (ODbL).

Kein Backend, kein Tracking, keine Cookies.
